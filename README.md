# 숨쉬는 반포길

반포·잠원(반포본동·반포2동·반포3동·잠원동)에서 **공사 먼지·교통 배기가스·꽃가루** 노출이 적은 보행경로와 한강공원 피크닉 자리를 찾아주는 웹 지도.

연세대학교 도시공학과 CRP2340 환경계획(2026-2) 팀 프로젝트

**바로가기:** https://whywhy4848.github.io/EP/

## 기능

- **길찾기**: 출발·도착을 검색하거나 지도에서 고르면 일반 경로(최단거리)와 저노출 우회 경로를 비교해 보여줌
  - 월·평일/주말·시간별 노출 반영, 12개월 노출 비교 차트
  - 네이버 지도 도보 길찾기 열기, 경유지를 찍어 네이버 경로에 맞춘 뒤 노출 비교
  - 내 위치에서 출발, 공사장 직접 추가
- **피크닉 장소**: 반포·잠원 한강공원을 40m 격자로 나눠 위험도(0–100)를 계산하고, 추천 3곳과 피하면 좋은 자리 1곳을 보여줌. 월별 공원 평균·최저 위험도 차트도 제공
- **기준 선택**: 설문 전체 응답자 / 꽃가루 알레르기 응답자 / 직접 조정
- 휴대폰에서 '홈 화면에 추가'하면 앱처럼 쓸 수 있음(PWA)

## 방법

| 요소 | 노출 지표 (링크·격자점별) |
|---|---|
| 공사장 | exp(−거리/75m). 평일 7–18시는 1, 그 외 시간은 0.15 |
| 교통 배기가스 | 간선 등급 가중(도시고속·고속 1.0, 주간선 0.7, 보조간선 0.45, 집산 0.25) × exp(−거리/50m). 출퇴근 시간 ×1.3 |
| 꽃가루 | 그 달에 비산하는 수목(위험도 상 1, 중 0.5) 커널합 exp(−거리/30m). 한강공원 물가는 3–4월 버드나무류 추정치 추가 |

- 링크 비용 = 길이 × (1 + Σ 가중치 × 노출). 다익스트라로 경로 탐색
- 저노출 우회 = 가중치 배율을 0~16배로 바꿔 찾은 후보 중, 우회 허용(기본: 최단거리의 1.3배) 안에서 노출이 가장 적은 경로
- 건물 안 링크(지하상가 등)는 노출 20%로 계산

### 설문 기반 가중치 (2026.9.30–10.1, n=56)

가중치는 요인별 평균(경험 빈도 0–3 × 불편 점수 1–5)으로 정하고, 세 요인 합이 4.5가 되게 맞춤

| 기준 | 공사 | 교통 | 꽃가루 |
|---|---|---|---|
| 전체 응답자 (56명) | 1.53 | 1.78 | 1.19 |
| 꽃가루 알레르기 (꽃가루 불편 4–5점, 14명) | 1.09 | 0.90 | 2.51 |

황사·미세먼지는 동네 안에서 경로마다 거의 같아 경로 선택에서 뺐음

## 한계

- 실제 대기질 측정값(S-DoT 등)은 반영하지 않은 노출 '지표'임
- 한강공원 안은 수목 자료가 없어 꽃가루는 추정치
- OSM에 등록되지 않은 공사 현장은 빠져 있음(지도에서 직접 추가 가능)
- 설문 응답자가 20대에 몰려 있고 대상지 거주자가 적음
- 역 위치는 대략값
- '일반 경로'는 최단거리 경로로, 네이버 경로와 다를 수 있음

## 구조

```
index.html            앱 (Leaflet, 서버 없이 브라우저에서 계산)
data/graph.json       보행 그래프 + 링크별 노출
data/picnic.json      한강공원 격자점별 노출
data/pois.json        검색용 장소
scripts/              데이터 생성 파이썬 코드
```

데이터를 다시 만들려면 `raw/`에 도보 네트워크 CSV를 받아 두고 `scripts/build_graph_seoul.py`를 실행한 다음 `scripts/build_picnic.py`를 실행하면 됨. 필요 패키지: shapely, pyproj, networkx, pandas, numpy
